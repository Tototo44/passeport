# Passeport

Appli Android de poche pour voyager :

- **Traduire** : français ⇄ anglais, langue détectée toute seule, traduction en direct.
  Mode **Rapide** hors ligne (sur le téléphone) et mode **Précis** en ligne avec DeepL.
- **Convertir** : euros ⇄ pesos philippins (PHP) au taux du jour, gardé en mémoire hors ligne.

Deux icônes sur l'écran d'accueil, chacune ouvre son tiroir avec le clavier déjà prêt.
Le **Carnet** regroupe le taux du jour, les montants gardés et la clé DeepL.

## Installer

Télécharger la dernière version depuis le téléphone :
https://github.com/Tototo44/passeport/releases/latest/download/Passeport.apk

L'APK est construit automatiquement par GitHub Actions à chaque modification.
